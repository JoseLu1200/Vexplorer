# Referencia reservada del evaluador

Esta carpeta no forma parte de la entrada, el runtime, las herramientas, los prompts, los endpoints, el índice histórico ni los artefactos servidos. Solo el evaluador la consulta después de congelar una salida.

La referencia es propia y sintética. No deriva de PlankAssembly ni del corpus mecánico. El fixture es de desarrollo y su construcción revisada no se presenta como la única solución compatible con las vistas.
